# SeaweedMat E01 — literature extraction (first tranche)

68 aggregate rows/plot readings: 45 exact table transcriptions and 23 approximate visual graph readings (16 Zhou, 7 Chamley). These are NOT independent raw replicate observations. The files deliberately separate exact published numeric tables from preliminary chart readings. Table 2 and Table 1 of Araya-Schmidt & Queirolo were visually verified against the uploaded PDFs during the initial extraction. Table 2 is used for the jute 3 day-56 value of 29.9 kgf; Table 3 gives 30.0 kgf. SD is derived from the rounded published CV times mean, not reported directly. Force conversion uses 1 kgf = 9.80665 N. Retention = 100 × group mean / baseline group mean; >100% retained rather than capped. No missing values were fabricated. The reported uncertainty on diameter is preserved without assigning it an SD interpretation.

The graph readings are approximate and rounded; error bars are not digitised. Source page and endpoint recorded per row. Do not pool absolute kgf, N/ktex and relative retention. No month-to-day conversion assumed. The same initial rayon normalised baseline is shown for both conditions, not independent observations. No zero-strength values are inserted for unobserved time points. Remaining figures/tables require additional extraction and validation. The four previously uploaded workbooks/archives are separate sources and are not included here. No local cultivation suitability or safe service life inferred.

The CSVs in this repository preserve the numerical transcriptions from the E01 package; derived numerical columns are recomputed from those values to the documented precision. Formatting/rounding may differ from the original local CSV.
